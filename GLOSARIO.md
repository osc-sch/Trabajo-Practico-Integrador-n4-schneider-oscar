
**Superconjunto**:	Lenguaje que incluye las características de otro y agrega nuevas funcionalidades. TypeScript es un superconjunto de JavaScript.

**Tipado estático**:	Sistema que permite comprobar los tipos de datos antes de ejecutar el programa.
Compilación	Proceso de traducir código de un lenguaje a otro.

**Transpilación**:	Tipo de compilación que convierte código entre lenguajes de nivel similar, como TypeScript a JavaScript.

**Type stripping**:	Proceso de eliminar las anotaciones de tipos de TypeScript sin realizar comprobaciones de tipos.

**Refactorización**:	Modificación de la estructura interna del código sin cambiar su comportamiento.
